# Buntal app

A minimal [Buntal](https://buntaljs.org) starter with Tailwind CSS.

```sh
bun dev                       # http://localhost:3000
bun run build && bun start    # production
```

Pages live in `app/`: add `app/about/index.tsx` and it is served at `/about`. Read the [docs](https://buntaljs.org/docs) or give your AI agent [llms-full.txt](https://buntaljs.org/llms-full.txt).
